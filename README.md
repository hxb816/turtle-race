# 🐢 跑跑龟 · The Great Turtle Race

一个可以直接在浏览器里玩的桌游小游戏：五只乌龟赛跑，打牌让它们前进或后退，谁先把自己颜色（秘密身份）的龟送到终点谁就赢。

**在线试玩** → https://hxb816.github.io/turtle-race/

纯前端、零依赖、单文件，手机和电脑都能玩。规则改编自 HKBU COMP2046 的课程设计《The Great Turtle Race》。

## 玩法

1. 棋盘 10 格，5 只龟（红蓝绿黄紫）从起点出发。
2. 每回合打一张手牌：让**卡牌指定颜色**的龟 `+1 / +2 / −1` 格。
3. 乌龟会**叠罗汉**：移动垫底的龟时，背上的龟会被一起带走；起点上的龟无法后退。
4. **彩虹卡**（+1 / −1）：由你指定任意一只龟移动，最强的调度牌。
5. **箭头卡 / 双箭头卡**：全场**最落后**的龟前进 1 / 2 格；并列最落后时由你选。
6. 出牌后补一张，手牌保持 5 张；牌堆抽空则弃牌重洗。
7. 每人开局随机分到一只**秘密颜色**的龟，你只知道自己的。电脑的颜色要到最后才公开——看它在帮哪只龟，就能反推它的身份。

支持 2~5 人（你 + 若干电脑对手），键盘 `1`~`5` 可快速出牌。

## 技术实现

- `index.html`：全部内容（游戏引擎 + 界面 + 样式），无构建、无依赖、无后端。
- 引擎与 UI 分离：`/* ===ENGINE_START=== */` 到 `/* ===ENGINE_END=== */` 之间是纯逻辑，不碰 DOM，可被 Node 直接测试。
- AI 使用启发式策略：推进自己的龟、拖住领先的对手、避免用自己的 −1 自残。

## 开发自检

```bash
node _dev/test-engine.js
```

会从 `index.html` 中抽出引擎跑 2400 局自动对战，校验：

- 52 张牌（40 普通 + 7 彩虹 + 3 箭头 + 2 双箭头）全程守恒
- 5 只龟不丢失、不重复、不越界
- 每局必然分出胜负，获胜者颜色合法
